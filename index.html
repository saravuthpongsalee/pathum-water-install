เมืองปทุมธานี · ESP32-CYD

ติดตั้งโปรแกรมลงบอร์ด
ผ่านสาย USB

เสียบบอร์ดเข้าคอม เปิดหน้านี้ด้วย Chrome หรือ Edge แล้วกดติดตั้ง ไม่ต้องติดตั้ง Arduino IDE หรือรับซอร์สโค้ด

รองรับ ESP32-CYD 2.8 นิ้ว รุ่นจอ ST7789 + XPT2046 เท่านั้น

เริ่มติดตั้ง

ใช้สาย USB ที่ส่งข้อมูลได้ เลือกพอร์ตของบอร์ด แล้วรอจนติดตั้งเสร็จ การติดตั้งครั้งแรกอาจลบค่าที่เคยบันทึกในบอร์ด

เบราว์เซอร์นี้เปิดพอร์ต USB ไม่ได้ กรุณาใช้ Chrome หรือ Edge บนคอม ต้องเปิดหน้านี้ผ่าน HTTPS เพื่อเชื่อมต่อ USB

กำลังตรวจไฟล์โปรแกรมสำหรับติดตั้ง…

หลังติดตั้ง: ตั้งค่า Wi-Fi ให้จอ

1 · ดูหน้าจอบอร์ดบอร์ดจะแสดงชื่อ Wi-Fi PATHUM-XXXXXXXX พร้อมรหัสเฉพาะบอร์ด
2 · ใช้มือถือเชื่อมต่อเชื่อม Wi-Fi ที่บอร์ดแสดง แล้วเปิด http://192.168.4.1
3 · กดบันทึกกรอก Wi-Fi บ้านแบบ 2.4 GHz และใส่ลิงก์เว็บกล้องที่ระบุด้านล่าง

ลิงก์เว็บกล้องที่ต้องกรอกบนมือถือ:
https://saravuthpongsalee.github.io/pathum-water

ดูภาพกล้องเดิม

เว็บกล้องเดิมยังอยู่ที่เดิม ภาพเป็นภาพนิ่งตามรอบ และแสดงเวลาของภาพก่อนนำไปใช้

เปิดเว็บกล้องเมืองปทุมธานี

เฟิร์มแวร์ต้องผ่านการทดสอบกับบอร์ดรุ่นเดียวกันก่อนเผยแพร่ หากไม่พบพอร์ต COM ให้ตรวจสาย USB หรือไดรเวอร์ USB-Serial ของบอร์ด
